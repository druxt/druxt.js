Tutorials are **learning-oriented**: they walk you through a project from
beginning to end, guaranteeing the outcome at every step. No prior Druxt
knowledge is assumed beyond the prerequisites stated at the start of each
lesson.

## Lessons

- [Getting started with Druxt.js](/tutorials/getting-started): set up a
  Nuxt application powered by a Drupal backend.
- [Building a custom Druxt module](/tutorials/first-custom-module): extend
  `DruxtModule` to create your own Druxt-powered components.
- [Add a login flow](/tutorials/authentication): turn the quickstart's
  already-configured OAuth setup into a real, working login.

If you already have a site running and want to accomplish a specific task,
see the [How-to guides](/how-to). To understand _why_ Druxt works the way it
does, see the [Concepts](/explanation) section.
