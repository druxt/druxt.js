title: Druxt modules
description: The Druxt packages, what each one renders, and how they fit together.
---

Druxt is built on two frameworks, Drupal and Nuxt, both with their own modules which can be used alongside Druxt modules.

Druxt modules provide Nuxt modules, plugins, components and more to
bridge the gap and make decoupled development easier.

New here? Start with [druxt-site](/modules/site), which pulls the rest
in and renders a whole site from the backend, then reach for the
individual modules when you need finer control.
